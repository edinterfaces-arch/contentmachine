# Content Machine

Проект городского Telegram-канала Уфы: источники → фильтрация → черновик → согласование → публикация.

**Статус:** перенесён контекст для разработки. Исполняемого приложения в репозитории пока нет.

Начните с [PROJECT.md](PROJECT.md): там решения, ограничения, источники, стиль и ближайшая задача. [AGENTS.md](AGENTS.md) содержит инструкции для Codex.

## Продолжить в Codex
Откройте этот репозиторий в Codex или клонируйте его и откройте папку в VS Code:

```sh
git clone https://github.com/edinterfaces-arch/contentmachine.git
cd contentmachine
```

Первый запрос:
> Прочитай AGENTS.md и PROJECT.md. Реализуй минимальный бот согласования с кнопками «Опубликовать» и «Пропустить», постоянным хранением решений и тестами. Сначала проверь текущую конфигурацию получения обновлений. Секреты бери только из окружения. Обнови документацию по фактическим результатам.

## Настройки
В [.env.example](.env.example) перечислены предполагаемые настройки. Файл пока только документирует конфигурацию: загрузчик и команды запуска предстоит реализовать.
Токены задавайте в локальном .env или секретах сервера, не в Git.
