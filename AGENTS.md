# Инструкции для Codex

- Сначала прочитайте PROJECT.md и существующий код.
- Общайтесь с пользователем по-русски, коротко и прямо.
- Различайте план, локальную реализацию, тестирование и реально запущенную систему.
- Не утверждайте, что бот работает или кнопки подключены, без проверки.
- Ближайшая задача — согласование черновика кнопками в Telegram. Не расширяйте её сразу до полной автономной редакции.
- Не публикуйте материалы без решения разрешённого редактора.
- Не переносите токены из истории чата в репозиторий. Конфигурация — из окружения; пример — только с пустыми значениями.
- Не печатайте токены, URL Bot API с токеном и Telegram-сессии в логи.
- До запуска получения обновлений проверьте существующий webhook/поллер.
- Храните решения между перезапусками; проверяйте повторные и конкурентные callback и неопределённый исход отправки.
- Выбирайте простой стек; документируйте команды установки, тестов и запуска после реализации.
- Обновляйте PROJECT.md по фактическому состоянию, сохраняя нерешённые вопросы.
